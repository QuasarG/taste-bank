# taste-bank

> The front-end style library for coding agents — distill a style once, reuse it everywhere.

[![Live](https://img.shields.io/badge/Live-tastebank.cloud-126984)](https://tastebank.cloud)
[![GitHub](https://img.shields.io/badge/GitHub-QuasarG%2Ftaste--bank-181717)](https://github.com/QuasarG/taste-bank)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This is the **taste-bank** npm package — a name reservation while the official
CLI is being built. The CLI will let you browse, fetch, and apply Taste Bank
front-end styles straight from the terminal, with no MCP configuration required.

## For now

- 🌐 **Browse styles** at [tastebank.cloud](https://tastebank.cloud)
- 🤖 **Use via MCP** — see the [setup guide](https://github.com/QuasarG/taste-bank#readme)
- 💬 **Source & issues** — [GitHub](https://github.com/QuasarG/taste-bank)
